# Open source notices

DP Talker itself is closed source (see the README). These are the third-party
components it incorporates, which keep their own licences. The same notices
ship inside the app under **About → Licences**, because an app with no INTERNET
permission cannot open a licence page and the technician reading it is in a
machinery space with no signal.

## Fonts

DP Talker currently renders with the system typefaces and bundles no font
files, so no font licence applies to the shipped build. If Saira and Spline
Sans Mono are ever bundled they are SIL OFL 1.1, and their notices must be
added here and to the in-app screen in the same change that adds the files.
